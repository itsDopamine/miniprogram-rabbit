## 3. 质量红线（每阶段都要满足）

- [ ] 控制台无报错、无未定义变量、无「找不到组件」
- [ ] 每个数据页都有 loading / empty / error 三态，断网不白屏
- [ ] 定时器、`wx.onXxx` 监听在 `onUnload` / `detached` 清理
- [ ] `wx:key` 使用业务 id，不用数组下标
- [ ] 页面里不出现 `wx.request`、不出现接口域名字符串
- [ ] 组件不自己发请求（数据由页面传入）
- [ ] `<image>` 均有宽高或 `mode`
- [ ] 颜色/字号走 `global.scss` 变量，不硬编码十六进制
- [ ] 主包体积处于合理范围（S8 起硬性 < 2MB）

## 4. 端到端用户旅程（全量回归）

按顺序走完，任何一步失败先修再继续：

1. **游客浏览**：启动 → 首页 5 区块出数据 → 点分类 → 二级分类 → 排序 → 触底加载 → 进详情 → 预览大图 → 选规格 → 加入购物车（未登录时按设计走本地车或提示登录）。
2. **登录**：进「我的」→ 跳登录 → 登录成功回到「我的」→ 头像昵称正确。
3. **购物车**：加 2 件不同商品 + 同商品重复加 → 改数量 → 取消勾选 1 件 → 杀掉小程序重进 → 数据与勾选一致。
4. **下单支付**：勾选 → 去结算 → 切换地址 → 提交订单 → 支付页倒计时 → 模拟支付 → 成功。
5. **订单查询**：订单列表切「待付款 / 待发货」→ 分页 → 进详情 → 取消一单 → 确认收货另一单。

## 6. 学习自评（闭卷回答，答不出就回看对应阶段）

1. 小程序为什么不能直接操作 DOM？`setData` 到底做了什么？

3. `properties` 和 `data` 的区别？为什么不能直接改 `this.data`？
4. `triggerEvent` 的第三个参数有什么风险？事件名为什么必须小写？
