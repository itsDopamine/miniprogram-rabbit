# 作业与准入闸门（总表）

> 本文件是**唯一进度看板**。每阶段结束前必须先过这里的闸门，才允许进入下一阶段。
> 详细操作在各阶段任务书 `stage-sX-*.md`，本文件只做汇总与勾选。

---

## 0. 三条规则

1. **必做作业全部完成才准入**。选做作业不设门槛，但结项时会被问到。
2. **每项作业必须有「可验证的提交物」**：代码、截图、终端输出、diff、对比表，缺一不可。「我做了」不算提交物。
3. **闸门答辩 3 问是「复述检验」，不是闭卷考试**。每份阶段任务书的「闸门答辩」一节**已给出参考答案**：先读答案 → 遮住 → 用自己的话讲一遍。讲不顺说明这一步是抄过去的，回看对应章节（返工方式见 §4）。

## 1. 提交规范

| 类型 | 位置 | 命名 |
| --- | --- | --- |
| 阶段复盘 | 各 `idoc/stage-sX-*.md` 末尾「复盘」一节 | 一个阶段一个文件 |
| 截图/证据 | `idoc/tmp/`（联调期临时，可清理） | `s1-401.png`、`s2-tabbar.png` |
| 概念笔记 | `idoc/notes/<主题>.md`（可选，需要时建） | `setdata.md`、`sku.md` |
| 代码 | `miniprogram/` 正常提交 | — |
| 提交信息 | Git | `feat(S2): 首页轮播与分类宫格` / `docs(S0): 阶段复盘` |

一次提交只做一件事；提交信息带阶段号，便于回看进度。

## 4. 闸门未通过怎么办

| 情况 | 处理方式 |
| --- | --- |
| 代码跑通但答辩答不出 | 不返工代码，回读该阶段文档与官方文档，用自己的话写一篇笔记，隔天再答 |
| 有提交物缺失（无截图/无数据） | 补做测量与记录，这本身就是「可验证」的训练 |
| 某项反复做不出 | 允许降级：拆成更小的一步（如 SKU 先只支持 2 组规格），在复盘里写明降级原因，结项前补齐 |
| 想跳过 S1 直接做页面 | 不允许。跳过请求层，后面每页都要返工 |
| S8 时间不够 | 允许只做 8-1 / 8-2 / 8-4，其余记为「未做」 |
